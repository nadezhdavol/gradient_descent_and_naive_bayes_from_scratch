## 🎯 Задание 2 — Наивный Байесовский классификатор для спама

### 📁 Данные

- **Источник:** учебный датасет `spam_or_not_spam.csv` (электронные письма со спамом и без)
- **Размер:** 2 999 писем, 2 столбца (`email`, `label`)
- **Распределение классов:**
  - `ham` (не спам) — **83.3%** (2 500 писем)
  - `spam` — **16.7%** (499 писем)

### 📊 Что сделано

#### 1. Предобработка текста
- Удаление `\W+` (не-словесных символов) и `\s+` (повторных пробелов);
- замена `_` на пробел;
- приведение к нижнему регистру;
- токенизация (разбивка на слова);
- удаление пустых строк (`dropna`).

#### 2. Разделение на train/test (80/20)
- `train`: 2 399 писем (2 002 ham / 397 spam);
- `test`: 600 писем (101 ham / 499 spam).
- **Важно:** разбиение случайное, стратификация не применялась — распределение классов в тесте сильно смещено в сторону спама (83% spam).

#### 3. Построение словаря
- Словарь построен по `train` и содержит **27 118 уникальных слов**;
- Построена частотная матрица «письмо × слово» (2 399 × 27 120).

#### 4. Расчёт вероятностей для формулы Байеса
- **Лапласово сглаживание** (`alpha = 1`) для избежания нулевых вероятностей;
- `P(spam) = 0.1655`, `P(ham) = 0.8345`;
- `Nspam = 137 855` слов, `Nham = 422 542` слова;
- Функции `p_w_spam(word)` и `p_w_ham(word)` возвращают условные вероятности с защитой от дубликатов колонок.

#### 5. Классификатор
- Логарифмирование вероятностей (защита от underflow при произведении маленьких чисел);
- Решение принимается по сравнению `log P(ham | w)` и `log P(spam | w)`;
- При равенстве — класс по умолчанию `ham`.

```python
def classify(message):
    log_p_spam = math.log(Pspam)
    log_p_ham = math.log(Pham)
    for word in message:
        log_p_spam += math.log(p_w_spam(word))
        log_p_ham += math.log(p_w_ham(word))
    if log_p_ham > log_p_spam:
        return 'ham'
    elif log_p_spam > log_p_ham:
        return 'spam'
    return 'ham'
```

#### 6. Оценка качества

| Метрика | Значение |
|---------|----------|
| **Accuracy** | **97.83%** |
| Ошибок всего | 13 из 600 |

**Типы ошибок:** все 13 ошибок — **ложноотрицательные** (спам классифицирован как ham). Это типично для несбалансированных данных при `alpha = 1` и без стратификации.

**Примеры ошибок:**
- пустые письма (`[]`) — классифицируются как `ham` по априорной вероятности;
- письма с «мусорными» токенами (`r, v, r, f, i, i, c, u...`) — слова не из словаря, поэтому вероятности сводятся к априорным;
- письма с редкими словами, встречающимися в `ham` тренировочной выборки.

## 🧠 Отработанные концепции

- **Градиентный спуск:** итеративное обновление весов `w -= α · ∇L(w)`, чувствительность к масштабу признаков, сходимость к глобальному минимуму.
- **Стандартизация:** обязательный шаг для устойчивости градиентного спуска.
- **Наивный Байес:** теорема Байеса, условная независимость признаков, лапласово сглаживание, работа с логарифмами для численной стабильности.
- **Обработка текста:** регулярные выражения, токенизация, построение словаря и частотной матрицы.
- **Метрика качества:** accuracy, R², RMSE, диагностика типов ошибок.
